dsh-plugins: eleven open-source plugins for DeepSeek Harness (dsh)

dsh-plugins is a collection of eleven open-source plugins for DeepSeek Harness (dsh), the agent harness built on the everything-is-a-plugin Cordis architecture, plus the self-hosted format-1 plugin market index that installs them. Each plugin is a standard DSH bundle: a Host half, an optional Web client half, and a cordis.patch.yml that wires it into the app.

dsh-plugins 收录十一个 DeepSeek Harness（DSH）插件：本地语音输入、语音看板娘与语音路由、GitHub 项目管理、会话归档与 PDCA 自改进、技能与 Agents 说明书体检、无限画布脑图、本机上下文资源库、外置任务账本、版本更新检查、长篇小说流水线；仓库同时自带一份插件市场索引，在 DSH 的「插件 → 发现」里填一个地址即可全部安装。全部插件均为 MIT 许可。

Install

Add this index URL in DSH under Plugins → Discover, then search for a plugin by its market title:

https://raw.githubusercontent.com/Feahter/dsh-plugins/main/index.json

From the command line, install a pinned release (this example is Voice companion 0.7.0):

dsh plugin install "git+https://github.com/Feahter/dsh-plugins.git#27d741d61fa63a072159de9049e411fc3696da80&path:/plugins/voice-companion"

The commit after # is the one recorded for that version in index.json; swap it for the version you want. Every plugin requires DSH >=0.2.1-rc.4 <0.3.0-0 — the exact range each package declares in its engines field.

Realtime voice input 实时语音输入

Realtime voice input writes speech into the DSH composer as cleaned-up text, with speech recognition running locally on the CPU.

点一次麦克风，连续说话，每个停顿的句子被清理后写进输入框；识别在本机 CPU 上用 SenseVoiceSmall（ONNX，int8）完成，音频不出设备。

  • Continuous dictation: every paused sentence lands in the composer, so a long thought does not have to be typed.
  • Offline sentence cleanup removes fillers, merges repeated words, follows self-corrections such as "no, I mean…", and normalizes punctuation and casing without spending model tokens.
  • Neighbouring sentences are polished together, so a misplaced pause or a half-corrected sentence is not inserted as-is.
  • Optional dictation translation: in translate mode a spoken Chinese sentence is written in English, and if translation is unavailable the original text is kept with a notice.
  • Exposes a ctx.get('voiceInput') service with attach/start/stop/toggle/settings, so other input surfaces can reuse the audio stack.
  • Replaces the built-in dictation button instead of sitting next to it: it registers at conversation.input.activity with priority: -1.

Version 0.4.0 Data browser localStorage key dsh.realtime-voice.settings.v2; no on-disk data directory Status superseded by Voice companion ≥0.4.0 Source plugins/realtime-voice

Voice companion 语音看板娘

Voice companion puts call mode, composer dictation and a hold-to-talk hotkey in one floating panel, and reads task progress back out loud.

一个面板覆盖整套语音面：通话模式逐句朗读、输入框听写、按住 Ctrl+Shift+Space 说话，再配一个可换形象与音色的看板娘。

  • Call mode runs energy VAD with sentence splitting, speaks each reply sentence by sentence, and reads task progress back.
  • A global Ctrl+Shift+Space hold-to-talk hotkey works while the DSH window has focus; if the combination is rejected it tries modifier-added candidates and falls back to an on-panel button.
  • The panel drags anywhere, remembers its position, and folds into a pill when it is in the way.
  • The stage defaults to a self-drawn 3D core (SDF ray-marched WebGL2, GLSL, no three.js, no textures, no network), with two original inline-SVG mascots (whale, chibi) still switchable; you can also use your own image as the avatar (resized to 512 px, stored in the browser) with one of three voice slots.
  • A task view draws one spoken task as a node chain — heard, dispatched, every tool call and reply, delivered — refreshing every 1.6 s and freezing into a snapshot when the task ends.

Version 0.7.0 Data browser localStorage (dsh.voice-companion.themes, .face, .pos, .hotkey); task records live in Host memory and clear on restart Source plugins/voice-companion

Voice control 语音控制

Voice control delivers one spoken sentence to the session it belongs to and speaks the reply back.

按住一个键说话，这句话被送进「该去的那个 Session」，回复用语音播回来；拿不准时先问，不猜。

Retired: the hotkey and session routing moved into Voice companion ≥0.4.0. This package still works at 0.2.0 but gets no new features, and both plugins bind Ctrl+Shift+Space, so enable one of the two.

  • Hold Ctrl+Shift+Space, release, and the HUD shows which session received the sentence.
  • Routing is one pure function in host/router.js covered by 17 unit tests, not a model call.
  • An explicit new-session phrase creates a session and uses the sentence as its first message; a strong title match resumes that session.
  • A plain "continue" goes to the single most recent candidate, and a locator phrase like "back to X" that matches no title speaks the candidates and asks for a number instead of guessing.
  • Anything under 0.6 confidence becomes a spoken confirmation, because a wrong route is worse than no route.
  • The Host half holds the API key and drives sessionController; the browser half records, shows the HUD and speaks, so the key never reaches the page.

Version 0.2.0 Data hotkey override in localStorage['dsh.voice-control.hotkey']; no on-disk data directory Source plugins/voice-control

GitHub project manager GitHub 项目管理

GitHub project manager adds a sidebar GitHub panel and a family of github_* agent tools to DSH.

侧边栏面板加一组 github_* 工具：浏览仓库与分支、处理 Issue、查看 Pull Request，复用本机 gh 登录，token 不下发浏览器。

  • Browse repositories and branches without leaving DSH.
  • Triage issues and create, close or comment on them from the panel or from a chat message.
  • Inspect pull requests and their conversation before reviewing.
  • Credentials are resolved on the Host from your existing gh auth login (including the macOS keyring) or from GH_TOKEN / GITHUB_TOKEN, and never reach the browser.
  • The panel and the tools share one implementation, so an issue created by a tool call shows up in the panel without a refresh.

Version 1.2.0 Data no data directory — credentials come from gh auth login or GH_TOKEN / GITHUB_TOKEN Source plugins/github-manager

Session archive + PDCA alchemy 归档会话与 PDCA 炼金

Session archive + PDCA alchemy curates DSH session history and mines it for measurable context fixes, closing the loop by re-measuring every patch it adopts.

给 Harness 的会话历史加上标签、笔记、搜索与回收站，再用 PDCA 循环把异常会话变成可度量的上下文修补，采纳后自己重估效果。全部本地计算，不调模型。

  • session_archive (actions: sync, list, read, update, autotag, delete) adds tags, notes, search and trash over ~/.dsh/sessions.
  • Original session files are never modified, moved or deleted; the Harness's own archive and pin state is mirrored read-only rather than forked.
  • rsi (actions: plan, run, status) computes tool-error rate, correction rate, the edit-then-no-verification gap, context pressure and tool-catalog cost, and turns outliers into findings carrying sessionId + seq evidence.
  • rsi_apply (actions: act, adopt) proposes context patches — prompt lessons, AGENTS.md rules, skill candidates — and applies or reverts one, with a backup written first.
  • The boot-time run re-measures adopted patches against the sessions on both sides of the adoption, so the loop closes without anyone remembering to ask.
  • 0.5.0 cut the resident tool surface from eleven tools to three, shrinking the tool catalog from 7352 B to 5231 B — context you pay for every step.

Version 0.5.0 Data ~/.dsh/archive-rsi/ Requires Node ≥ 22.15 Source plugins/archive-rsi

dsh-360 — two health checks in one dsh-360 两面体检

dsh-360 scores two health surfaces — the skills catalog and everything injected into agent context — on one shared 18-bucket S~E grade scale.

一个面板两份体检：技能目录按需加载这条路走不走得通，以及 AGENTS.md、子代理定义、agent preset 这些每轮都注入的内容值不值这个 token。四轴分类，同一套 S~E 等级。

  • The skills surface scores each catalog entry's on-demand loading path: catalog selectability, real load evidence, trigger uniqueness, progressive disclosure, actionability, boundaries, hygiene and evolution.
  • The agents surface scores everything injected into context — AGENTS.md / CLAUDE.md, subagent definitions and agent presets — for injection hit rate, resident token cost, layering, imperative rules with verification commands, scope and cross-file conflicts.
  • Every item gets a four-axis classification (role / kind / scope / state) plus, for skills, a split between meta skills and task skills.
  • The panel paints the last snapshot before revalidating, keeps filters behind one icon, and shows optimization cards with what changed and a real undo.
  • Four dsh360_* tools take a surface parameter (skills, agents or both); every write is backed up and undoable.

Version 0.3.0 Data ~/.dsh/dsh-360/ (backups, reports, state, cache) Requires Node ≥ 22.15 Source plugins/dsh-360

Mind canvas 脑图创意画布

Mind canvas is an infinite-canvas mind map that runs inside the DSH sidebar and exports to formats other outliners can open.

侧边栏里的无限画布脑图：Tab 长出子节点、一键整理成不重叠的树、AI 发散、从自媒体工作台导入灵感，可导出 Markdown / OPML / FreeMind / JSON / PNG。

  • Jot a thought and press Enter for the first node; Tab grows a child and drops straight into editing, ⌘Z undoes, and deleting a node takes its whole subtree.
  • Tidy up runs a d3-hierarchy tidy-tree layout so siblings never overlap, growing right or down, and any node can collapse its subtree.
  • Five theme presets (paper, midnight, forest, sunset, indigo) plus a custom palette of 13 colour slots; Follow app inherits the host's light and dark tokens, and all 14 colour pairs pass WCAG 4.5:1.
  • From inspirations imports entries from the Media desk plugin as roots; AI branch asks the host's default model for 3–6 concrete child ideas and fails loudly instead of inventing content when no model is configured.
  • Export to a Markdown outline, OPML (XMind / MindNode), FreeMind .mm, raw JSON or PNG.
  • Agent tools mind_canvas_read (outline plus stats) and mind_canvas_add (branch a node by text match) let the model work on the same map.

Version 0.4.0 Data ~/.dsh/mind-canvas/state.json Source plugins/mind-canvas

Context library 上下文资源库

Context library indexes the files already on this machine into one searchable library that the agent can read as context.

把本机的 Markdown、代码、图片、PDF、Office 文档与会话日志索引成一个可检索的资源库，扫描只登记不改动原文件，并给 agent 九个 context_lib_* 工具。

  • Sources are directories: scans respect a depth cap and an extension whitelist and register files by size and mtime, so a rescan only touches what changed.
  • Linked files are only ever described — never moved or deleted.
  • The panel gives search plus type, collection and tag filters, a detail view with notes and editing, trash and restore, and four view modes (list, cards, table, gallery).
  • Local previews without a parser zoo: textutil converts doc/docx/rtf/odt, qlmanage renders pdf/xlsx/ppt thumbnails cached by file plus size plus mtime, and HTML is stripped to text.
  • Nine context_lib_* tools — search, read, put, update, delete, scan, stats, sources, pack — plus a short library briefing injected every turn.
  • Pack a collection into one readable block when a whole topic has to be loaded at once.

Version 0.3.1 Data ~/.dsh/context-lib/ (index.json, notes, blobs, cached thumbnails) Requires macOS for previews Source plugins/context-lib

Task ledger 任务账本

Task ledger keeps goals, decisions, evidence and next actions in an external ledger so a task outlives the session that started it.

把状态所有权从会话搬到外置账本：目标、决策、证据、下一步都在磁盘上，关掉会话、换模型或换 agent 之后，交回 task_id 就能续跑。

  • Five tools: task_list, task_open, task_resume, task_checkpoint and task_close.
  • task_resume takes a single-writer lease and returns a run_id, so two runs cannot quietly write the same ledger.
  • task_checkpoint writes evidence, claims, decisions and next actions under an optimistic expected_version.
  • A closeout evidence gate runs before a task may be marked done; a failing gate downgrades done to blocked unless the override is recorded as a decision.
  • The sidebar panel reads the ledger directly rather than keeping a second copy of it.
  • A failed ledger write is reported in the run report instead of being silently swallowed.

Version 1.1.0 Data ~/.dsh/task-ledger/ (state.json, task.json, JSONL logs) Source plugins/task-ledger

Version update check 版本更新检查

Version update check reads the installed DSH version from the app bundle and the newest version from your update feed, then hands an available upgrade to the in-app updater.

侧边栏面板回答「我现在跑的是哪个版本、有没有更新」：当前版本从安装包本体读，最新版本从桌面端自己的更新源读，有新版就交给应用内更新器。

  • The installed version is read from the app bundle itself (Info.plist or the packaged manifest), not guessed from a filename.
  • The newest version comes from your configured update source — the same app-update.yml electron-updater uses.
  • One button hands the upgrade to the in-app updater: download, verify, confirm restart.
  • The page never shells out and never replaces a signed .app.
  • In a plain browser with no preload bridge it says so and turns the button into a download link.

Version 0.2.0 Data no data directory — reads the app bundle and your configured update feed Source plugins/update-check

Ink Furnace — novel forge 墨炉 · 小说炼炉

Ink Furnace — novel forge runs one premise through a resumable stage pipeline to a finished, continuity-checked novel.

一句话故事核进，成稿小说出：设定、人物、情感脊柱、大纲、细纲、正文、连续性审校、修订、导出 Markdown / EPUB，全流程按条目断点续跑。

  • The pipeline runs premise, world bible, characters, emotional spine, outline, per-chapter beats, prose, continuity review, revision and Markdown/EPUB export as explicit stages.
  • A generic stage engine that knows nothing about novels drives the recipe, so every stage resumes per item and a run can stop and continue at chapter granularity.
  • Malformed review JSON is salvaged instead of discarded, and chapter summaries are written in the same call as the prose they belong to — 78 to 54 calls and 27% less input on a 12 × 3000-word book.
  • Pronouns are tracked per character with a deterministic drift check, so a female lead is not rewritten as "him".
  • Volume-to-chapter outlines build volume skeletons by script instead of model calls, and the first turn produces a golden-three-chapters opening pack.
  • novel_* tools activate per session, so a session that is not writing a novel carries zero resident tokens.

Frequently asked questions

What is DeepSeek Harness?

DeepSeek Harness (dsh) is an open-source agent harness from DeepSeek AI, built on an everything-is-a-plugin architecture powered by Cordis. It runs as a local Web UI or desktop app, and plugins add panels, tools and services to it.

What is dsh-plugins?

A repository of eleven DSH plugins plus a self-hosted format-1 plugin market index (index.json). Adding the index URL in DSH Discover makes all eleven installable from one place.

Are these official DeepSeek plugins?

No. dsh-plugins is an independent community project maintained by Feahter. It targets the public DSH plugin API and is not published or endorsed by DeepSeek.

How do I install a plugin?

Open Plugins → Discover in DSH, add https://raw.githubusercontent.com/Feahter/dsh-plugins/main/index.json, then search for the market title. Command-line installs use dsh plugin install with the commit recorded in index.json for that version.

Do the plugins send my data anywhere?

Almost never. Recognition, session analysis, scoring, indexing and the ledger all run locally. The exceptions are: the sentence text in realtime-voice translation mode; reply text sent to your TTS provider; model calls for novel-forge, the mind-canvas AI branch and the voice-companion theme designer (one sentence goes out, a sanitized theme patch comes back); GitHub API calls made with your token; and the update-check version request to the desktop app's own update feed.

Do I need an API key?

Only for the features that call a model: novel-forge, the mind-canvas AI branch, realtime-voice translation and voice-companion speech output. Everything else runs without one.

Which plugin should I install first?

If you want to stop typing, start with Realtime voice input. If you want the agent's state to survive sessions, start with Task ledger.

Where is plugin data stored?

Under ~/.dsh/<plugin>/ for the plugins that keep a directory; the voice plugins keep settings in browser localStorage. Nothing is written into the DSH app bundle, and original session files are never modified, moved or deleted.

Which plugins need Node 22.15 or newer?

All eleven packages declare node >=22.15 in their engines field, so that is the supported runtime for every plugin; archive-rsi and dsh-360 need it because they decode concatenated-zstd session logs through node:zlib. macOS is required only for the context-lib document previews.

Can I run two voice plugins at the same time?

No. voice-companion and voice-control both bind Ctrl+Shift+Space, so enable one of the two. The dictation half of realtime-voice and the hotkey of voice-control already live inside voice-companion.

Does it work offline?

Yes for everything that stays on the machine: speech recognition (SenseVoice ONNX int8), sentence cleanup, session analysis, scoring, indexing and the task ledger. Features that call a model or a TTS provider — novel-forge, the mind-canvas AI branch, theme design, translation and speech output — need network access and a configured provider.

Is it free?

Yes. All eleven plugins and the market index are MIT licensed, so there is no price, no account and no telemetry. Model calls made by a plugin are billed by whichever provider you configured in DSH, not by this repository.

Which platforms does it run on?

Wherever DSH runs: the plugins are Node packages plus Web-client panels, with no native build step. macOS is required only for the context-lib document previews; everything else makes no platform-specific call.
