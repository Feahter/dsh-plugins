# 语音三件套：热键降级 + 麦克风权限引导

范围：`plugins/voice-companion`、`plugins/realtime-voice`、`plugins/voice-control`。版本号保持 0.4.1 / 0.3.1 / 0.1.1，未改 `index.json`，未装依赖，未 commit。

## 三个插件各自的降级路径

| 插件 | 热键绑定失败 | 应用内替代入口 | 麦克风拒绝/不可用 |
| --- | --- | --- | --- |
| voice-companion | 原键 → `Alt` 变体 → `Ctrl` 变体 → 应用内按钮；面板黄色/红色通知条显示最终生效项，HUD 也提示 4 s | 面板新增「按住说话」行（仅降级时出现），pointer/键盘按住即走同一条 hotkey 管线 | 面板常驻一行「仅本机识别」；首次通话前一次性说明；失败按 permission / no-device / busy / unavailable 分别给文案与恢复步骤；再次点「开始通话」重新 `getUserMedia` |
| realtime-voice | 新增 `Alt+Shift+D` 开关听写；绑定失败时试 `ControlLeft` 变体，再退回麦克风按钮；浮动条与设置页显示实际生效项 | 麦克风按钮本身（始终存在），错误文案直接写「点麦克风重试」 | 先请求麦克风再准备模型（拒绝不必等模型）；拒绝/无设备/被占用分别文案；`permission` 状态不缓存；再次点麦克风重试 |
| voice-control | 原键 → `Alt` 变体 → `Ctrl` 变体 → 右下角按钮；HUD 显示最终生效项或降级提示，首次成功绑定额外提示「仅窗口聚焦时生效」 | 右下角常驻「按住说话 / Hold to talk」按钮（pointer 按住/松开） | 拒绝/无设备/被占用三分文案（含 macOS 设置路径），HUD 错误停留 9 s，处理后可重新按键 |

### 冲突检测的真实边界

- 可检测并已处理：`addEventListener` 抛错（宿主/权限拒绝键盘事件）、浏览器保留组合（Ctrl+W/T/N/R、Cmd+Q/W/M/R、Alt+F4）。
- 不可从 Web 层检测：另一个应用在系统层抢走按键。插件侧没有 `globalShortcut`，因此这种情况只能通过「绑定失败/保留键」的可视化 + 常驻应用内按钮兜底；README 已写明这一限制，真正的系统级热键需要改原生壳。

## 文案与入口

统一中英双语，失败信息都带「发生了什么 + 怎么继续」：

- voice-companion 热键：`热键 X 无法注册（可能被其他应用占用），已切换到 Y。 / Hotkey X could not be registered (maybe taken by another app); using Y instead.` + `也可用面板「按住说话」按钮。 / The panel’s “Hold to talk” button always works.`
- voice-companion 全部候选失败：`热键不可用（可能被其他应用占用，或只在窗口有焦点时生效）… 请用面板「按住说话」按钮。 / Hotkey unavailable — it may be taken by another app, and it only works while this window is focused…`
- 麦克风拒绝：`麦克风权限被拒绝 · Microphone access denied — macOS：系统设置 → 隐私与安全性 → 麦克风，允许 DeepSeek Harness 后重试 / … System Settings → Privacy & Security → Microphone, then retry.`
- 无设备：`没有检测到麦克风 · No microphone found — 请连接麦克风… / connect a microphone…`
- 被占用：`麦克风被其他应用占用 · Microphone is busy — 关掉正在使用麦克风的应用后重试 / quit the app using the mic, then retry.`
- 首次说明：voice-companion 面板常驻 `麦克风仅在本机识别，音频不出机器 · Mic audio stays on this device.`，首次点击再出一次性提示；realtime-voice 设置页输入分页常驻用途说明，首次点击麦克风前浮动条出一次性提示。
- realtime-voice 热键提示：失败时浮动条/设置页显示 `热键 X 无法注册（可能被其他应用占用），已切换到 Y` 或「点麦克风即可听写」；成功时设置页写 `快捷键 X 开关听写；热键只在窗口聚焦时生效`。

## 未验证项（不要当成已验证）

- **真实麦克风与系统权限弹窗**：没有在真实浏览器/桌面端点过 macOS TCC 弹窗；假 `getUserMedia` 只验证了错误名到文案/重试路径。
- **真实系统级热键冲突**：没有用另一个应用真实抢占按键；Web 层拿不到 `globalShortcut`，实际系统抢占只能靠应用内按钮兜底，无法自动识别。
- **Electron `setPermissionRequestHandler`**：按边界未改主进程；宿主仍需自行收紧权限。README 已写入。
- **运行中桌面端的 HMR/重载表现**：没有在 GUI 里实际安装这三份新 client 后点按验证；测试是离线 harness。
- **真实键盘布局/输入法**：`KeyboardEvent.code` 候选在 macOS 不同布局、中文输入法下的行为未实测。
