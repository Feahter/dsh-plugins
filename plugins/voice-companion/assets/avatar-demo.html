同一份 characters.js 渲染：五状态 + 两个形象 + 切换 / 对话·听写开关。改完 art 直接刷新这页。

怎么验

1. 右上两个圆点切看板娘：大 胖鲸鱼 / 小 二次元看板娘；切换后面板底色、字幕、音色都跟着换（音色由宿主侧 host/voice.js 决定）。

2. 右上「对话 / 听写」按钮切换麦克风去向：对话=回话，听写=写进输入框。

3. 下面一排是 data-state 五个状态的静态定格（真实动效由 CSS 关键帧驱动，这里为了并排展示被冻住）。

4. 按住面板顶部那条可以拖着走（松手记住位置）；右上「−」把它折成一颗胶囊，点胶囊又能展开。
