- **`fakePrompts()` 的 builder 全部返回固定 `user:'写。'`，不读 `ctx.packet`**。所以集成测试想验证材料包，必须自建 engine 覆盖 `prompts.draft = (ctx) => { packets.push(ctx.packet); ... }`，直接断言 `llm.calls[].user` 只会拿到「写。」。

- **`checkOpeningContract` 早在 `outline.js:294` 就有且有测试**，缺的是生产调用点。接线比重新实现便宜十倍。

- `reviewGate` 默认 false（`index.js:69-70`）：note 级 finding 只记录，不触发修订。别以为加了 note 就会自动改稿。
